# 📰 TruthAI – AI Fake News Detection

## 📌 About the Project

TruthAI is an AI-powered Fake News Detection website designed to help users analyse news headlines and articles in English and Marathi.

The project aims to help users assess the credibility of news and identify potentially misleading information using Artificial Intelligence.

## 🎯 Project Objectives

- Detect potentially misleading news.
- Analyse news headlines and articles.
- Support English and Marathi news.
- Provide a simple, mobile-friendly interface.
- Encourage users to verify news before sharing it.

## 🚀 Features

- 📰 Newspaper-style background.
- 🤖 AI-powered news analysis (requires model integration).
- 🌐 English and Marathi interface.
- 📱 Mobile-responsive design.
- ⚡ Simple and user-friendly interface.
- 🔍 News credibility assessment.

## ⚙️ Installation

### Step 1: Clone the repository

git clone https://github.com/YOUR-USERNAME/truthai-fake-news-detector.git

### Step 2: Open the project folder

cd truthai-fake-news-detector

### Step 3: Install Python dependencies

pip install -r requirements.txt

### Step 4: Start the backend

uvicorn backend:app --host 0.0.0.0 --port 8000

### Step 5: Open the website

Open index.html in your browser.

Note: Configure a suitable AI model and backend URL before using
the news analysis feature.

## 🌍 Deployment
